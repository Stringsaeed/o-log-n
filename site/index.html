Two surfaces, no window

It shows up when you drag.

Logn lives in the menu bar. Start dragging any file, anywhere, and a glass capsule slides in at the top-centre of the screen. Hold ⌥ to flip the two halves.

  1. Smart The smallest file that still looks or sounds identical.

  2. Lossless Exact content, checked before it’s written.

  3. Working The halves merge into one progress pill.

  4. Done The saving, then it gets out of your way.

Real screenshots from the app’s built-in demo mode. The file names and figures inside them are placeholders, not measurements.

Control Option Space⌃⌥Space opens the tray.

A Liquid Glass tray across the bottom quarter of the screen, with the live queue, history and settings. It opens in about 65 ms.

Safety

Squeezed. Nothing essential lost.

  1. 01

    The original is never overwritten.

    Logn writes a new file. Yours stays exactly where it was, exactly as it was.

  2. 02

    The output is never larger.

    If nothing can be saved, Logn says “Already optimal” instead of handing you a bigger file.

  3. 03

    Lossless is checked.

    Every lossless result is verified against the original before it’s written.

  4. 04

    Replace can be undone.

    Replace original moves the original to the Trash, and ⌘Z undoes it.

How it works

Mostly your Mac itself.

Native Apple frameworks

  • ImageIO
  • VideoToolbox
  • AudioToolbox
  • PDFKit / Quartz
  • Compression

Two vendored open-source libraries

  • libdeflate MIT
  • libjpeg-turbo BSD / IJG

Logn’s own

  • PNG optimiser
  • Oklab colour quantiser
Where it runs
On your Mac. Everything happens on device.
Network
None.
Account
None.
Requires
macOS 26 or later, on Apple Silicon.
The name
The repo is called o-log-n, as in O(log n): big input, small result.
