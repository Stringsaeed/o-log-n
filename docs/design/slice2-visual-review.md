# Slice 2 Visual Critique & Prioritized Fix List

Reviewed against `docs/design/ux.md`, the 2× Retina captures (`tray-open.png` `1400×329 pt`, `jobs-after-halves.png` `1400×329 pt`, `dropzone-expanded.png` `360×140 pt`), and `Sources/OLogNApp/Views/`.

## Key Visual Measurements from Captures

- **Queue misalignment (`jobs-after-halves.png`)**: Queue canvas spans `x = 308…1368 pt` (`1060 pt`), but cards center at intrinsic widths — Row 1 at `x = 551…1120` (`569 pt`), Row 2 at `x = 584…1086` (`502 pt`), Rows 3–4 at `x = 613…1058` (`445 pt`) — staggering edges by `62 pt`.
- **Muddy olive (`tray-open.png`, `jobs-after-halves.png`, `dropzone-expanded.png`)**: No bundle `AccentColor` exists, so `Color.accentColor` inherits macOS Yellow/Green accent; at `0.18–0.22` opacity over dark glass (`#303030` / `#3D3845`) it composites to olive drab (`#5E644C` / `#666A51` / `#5B5D51`), with an AppKit focus ring (`#A1A475`) on `Smart`.
- **Backdrop bleed (`jobs-after-halves.png`)**: Un-scrimmed `.glassEffect(.regular)` + `Color.clear` `IntakeWell` leaks warm brown (`#5E5337`) and slate-teal (`#42504C`) desktop blobs directly behind `.secondary` text (~`2.6:1` contrast).
- **Baseline jump (`dropzone-expanded.png`)**: Targeting `Smart` (`y = 54.1…67.2`) hides `Lossless`'s subtitle, dropping `"Lossless"` to `y = 61.8…74.2` (`7.7 pt` lower) with `1.35:1` half-to-half contrast.
