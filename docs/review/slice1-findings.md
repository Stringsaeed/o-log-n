# Slice 1 review findings (GPT-6.2 Astra), triaged by the orchestrator — all 20 accepted

Line numbers refer to the snapshot commit in this checkout. "Reproduced" means the reviewer demonstrated it.

## High
1. **Folder archive written inside the source folder** (reproduced). Compressing a folder with `--out` set to that folder created `folder/folder.tar.xz` and mutated the original tree. Fix: reject destinations equal to or beneath the source (after resolving symlinks) with `JobError.outputNotWritable("destination is inside the source folder")`. The test must take the source-tree digest BEFORE submission (the current test takes both digests after). Refs: CompressionEngine.swift:243, Tests Fixtures.swift:261.
2. **Stale input size in the final gain gate** (reproduced). A 20,000-byte file was queued and shrunk to 5 bytes while waiting; the engine published a 56-byte .xz claiming 99.72% saved. Fix: capture the source fingerprint (size, mtime, inode/fileID) when processing starts; revalidate before publication (changed → `JobError.unreadable("source changed during compression")`); compute the gain against the start-time size. Expose the fingerprint additively on `JobResult` so Replace Original can detect later edits. Refs: CompressionEngine.swift:51, :190.
3. **Smart PNG turns tRNS-transparent pixels opaque** (reproduced). An RGB PNG whose tRNS made black transparent went through the palette path; output alpha was 255, and the luma-only SSIM accepted it. Fix: apply tRNS before the opacity test and the palette path; compare alpha independently of luma, so any alpha change beyond tolerance rejects palette. Refs: PNGFormat.swift:214, PNGCodec.swift:35.
4. **Smart video drops an alpha channel** (reproduced). A translucent ProRes 4444 MOV produced a "verified" HEVC with no alpha. Fix: detect alpha on the video track (format description extensions / `kCMFormatDescriptionExtension_ContainsAlphaChannel`, ProRes 4444 / HEVC-with-alpha codec types) before creating the reader, and skip per §3.4. Refs: VideoCodec.swift:24, :122.
5. **Quarantine xattr lost on read-only sources** (reproduced). A 0444 JPEG carrying `com.apple.quarantine` produced a 0444 output without the attribute: permissions were applied first, and `setxattr` failures were ignored. Fix: copy the xattrs while the scratch file is writable, check the results (failing to copy quarantine is a job failure), and apply final permissions last. Refs: OutputWriter.swift:139, :165.
6. **JPEG shim can free a stale destination buffer on error** (source review). If libjpeg grows the mem destination and then fails before `term_destination`, the original allocation has already been freed while the caller's `buffer` still points to it; the longjmp handler `free(buffer)`s it. Modified automatics also cross longjmp. Fix: put all mutable state in a heap or static-lifetime context struct, and use a custom destination manager with explicit buffer ownership through growth and error cleanup. Refs: Vendor/libjpeg-turbo/ologn/ologn_jpeg.c:156.
7. **Unbounded image memory** (source review). PNG allocates from unchecked decoded dimensions, and SSIM allocates five full-resolution Double tables: about 1.92 GB for a 48 MP photo before anything else. Fix: checked multiplication on all decoded-size arithmetic, a per-job working-memory budget checked before allocation (over budget → `skipped("image too large for Smart")` or lossless-only), and SSIM over 8×8 windows with rolling row sums so memory is O(width), not O(pixels). Results for the samples must stay identical (same q-picks for 03/05). Refs: PNGFormat.swift:120, Metrics/SSIM.swift:81.
8. **Disk-full pause doesn't stop jobs already waiting for a lane** (source review). The next waiter starts without rechecking `paused`, and some write failures (e.g. a failed video append) surface as cancellation and bypass the pause. Fix: recheck pause after lane acquisition and keep the job queued until `resume()`; preserve the underlying write error through codec failure paths. Refs: CompressionEngine.swift:150, VideoCodec.swift:182.
9. **Event replay can deliver `.updated` before `.added`** (reproduced: 68 of 480 jobs with concurrent subscribers). Fix: serialize subscriber registration, snapshot replay and event publication under one ordering mechanism (all inside the actor; register and replay atomically before any later publish). Add a stress test. Refs: CompressionEngine.swift:25, :373.
10. **Intake and verification block cooperative threads** (reproduced for JPEG: a 10 ms heartbeat stalled 354 ms with 12 lossless JPEGs). Also, `submit` walks folders synchronously on the actor, blocking `jobs()` and `cancel()`. Fix: `submit` returns IDs immediately and the walk/size computation happens off-actor (job shows `inputBytes` once known: keep the API shape and emit `.updated`); move all blocking work into `Offload.run` with cancellation polling, including PNG verify, FLAC decode/hash, JPEG read/transcode/verify, and verifier subprocess waits. Refs: CompressionEngine.swift:50, JPEGCodec.swift:24, LosslessVerifier.swift:53.

## Medium
11. **`verify` certifies unrelated archives** (reproduced). A text file vs a zip with different content exited 0, and an empty file vs a zero-byte .xz exited 0. Fix: for zip, compare entries and contents to the source (file or folder tree); for xz, require at least one completed stream.
12. **FLAC verify ignores sample rate and channel layout** (reproduced: a 22,050 Hz WAV vs a 44,100 Hz FLAC with the same samples passed). Fix: include sample rate and channel count in the equality check. Ref: AudioCodec.swift:65.
13. **Cancel can end as a verified `alreadyOptimal`** (reproduced: Smart HEIC cancelled 10 ms after `.running`). Fix: check cancellation immediately after the codec returns, before interpreting its outcome; add a test that cancels during codec work. Refs: CompressionEngine.swift:172, HEICCodec.swift:40.
14. **Smart JPEG progressive fallback keeps metadata the user chose to strip** (reproduced with a COM marker). Fix: apply the Smart metadata policy (D18: keep ICC and orientation, strip the rest when `stripMetadataInSmart`) on this path. Ref: JPEGCodec.swift:32.
15. **Lossless JPEG drops the JFIF thumbnail** (reproduced: a 1×1 thumbnail became 0×0). Fix: preserve the original APP0 payload and suppress the generated duplicate JFIF header. Ref: ologn_jpeg.c:69.
16. **Palette PNG writes iCCP after PLTE** (reproduced). PNG requires iCCP (and sRGB, gAMA, cHRM, sBIT) before PLTE. Fix: correct chunk ordering in both indexed writers, plus a test that asserts order independently of pixel equality. Refs: PNGFormat.swift:188, :612.
17. **Packed-palette PNGs fail lossless verification** (reproduced: a 65-px-wide 1-bit indexed PNG with tRNS failed with `palette index`). The verifier scales index 1 to 255 before lookup. Fix: return the raw packed value for indexed images and scale only for gray. Test 1-, 2- and 4-bit palettes with odd widths. Refs: PNGFormat.swift:519, :580.
18. **Portrait video rotation applied twice** (reproduced: the 1080p sample remuxed with 90° rotation failed with `video dimensions differ`). iPhone portrait videos would all fail. Fix: configure the writer with the encoded `naturalSize`, copy `preferredTransform` once, and verify encoded and display dimensions separately. Refs: VideoCodec.swift:31, :146.
19. **`waitUntilFinished` on a removed job never returns** (reproduced). Fix: keep the API signature and retain a tombstone of the terminal Job after `remove` so waits return it; an unknown ID returns immediately with a `.cancelled`-state placeholder (document this). Ref: CompressionEngine.swift:113.
20. **`JobResult.duration` includes lane wait** (reproduced: a zip took 31,152 ms in a 41-job batch vs 3 ms alone). Fix: start the timer after lane acquisition, and run the cheap archive/magic skip gate before wide-lane admission so instant skips aren't queued behind archives. Ref: CompressionEngine.swift:142.
